# My First Django App

A beginner-friendly web application built with **Django**, designed to demonstrate foundational backend concepts, database integration, and standard Django project architecture.

---

##  Features

* **Django ORM & Models:** Manages database entities and relationships seamlessly using Django's built-in Object-Relational Mapper.
* **Admin Dashboard:** Out-of-the-box administrative panel for managing application data.
* **Routing & Views:** Clean URL routing and structured view controllers handling HTTP requests and responses.
* **Environment Configuration:** Secure separation of sensitive configurations using environment variables (`.env`).

---

## 🛠 Prerequisites

Make sure you have the following installed on your machine:
* Python (version 3.10 or higher recommended)
* Git
